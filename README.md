## 🪐 About Me

```yaml
name: "Atharva"
role: "B.Tech CSE Student (Software Engineering Track)"
location: "India"
focus: "Backend Engineering + Generative AI Applications"
currently_building: "A RAG-based Codebase Q&A Assistant (LangChain + ChromaDB + Groq)"

```

I'm a software engineering student building toward **backend + AI application engineering** roles — the kind of work that sits at the intersection of solid systems thinking and the new generative AI stack.

My approach is deliberately layered:

- 🏗️ **Foundations** — Data Structures & Algorithms in Java, SQL, and core backend principles, because AI features built on weak engineering don't hold up in production.
- ⚙️ **Backend Engineering** — REST APIs and services with **FastAPI**, backed by **PostgreSQL**, designed the way a real product would need them.
- 🤖 **Generative AI** — Practical, production-shaped work with **LLM applications**, **Retrieval-Augmented Generation (RAG)**, **LangChain**, and **vector databases** like **ChromaDB** — not toy demos, but systems with retrieval pipelines, chunking strategies, and source-cited answers.
- 🧩 **Agentic AI** — Early but active exploration of **AI agents**, **tool calling**, and **automation workflows** as the next layer on top of RAG.

I'm not claiming to be a finished product — I'm an engineer-in-progress who builds in public, ships real (if imperfect) projects, and treats every one of them as a rep toward the engineer I'm becoming.
